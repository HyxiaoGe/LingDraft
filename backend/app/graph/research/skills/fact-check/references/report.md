## 报告结构

1. 结论：这个说法对不对、准确的数是多少（附口径）；证据不足就直说。
2. 源头怎么说：一手来源的原始表述和条件。
3. 不同说法的出处和口径：每种说法是谁说的、算的是什么、和源头差在哪里。
4. 仍不确定或没找到源头的地方。

没有内容的节省略，不要为了凑结构编内容；只有一种说法时，第 3 节可以省略。

## 论断的写法

好的论断，写清说法的出处和口径：
- 「某市统计公报写明，2025 年末常住人口为 X 万人。」
- 「流传较广的 Y 万人出自一篇媒体报道，算的是户籍人口，和统计公报的常住人口不是同一个口径。」

不好的论断：
- 「某市人口是 X 万。」没说口径，读者会以为所有统计都是这个数。
- 「Y 万的说法是错的。」口径不同不等于错，要说清差在哪里。
