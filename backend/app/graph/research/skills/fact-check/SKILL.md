# 事实核查

## 1. 把要核实的说法拆清楚

- 写下要核实的到底是什么：哪个对象、什么指标、什么时间、什么口径。一个说法里有几个可以核实的点时，分开核实。

## 2. 追到源头

- 找最初发布这个信息的地方：官方公告、论文、财报、统计公报、监管文件、当事方的原话。转述的报道只用来找线索，最后要引用源头。
- 找不到源头时，说明目前能找到的最早出处在哪里，不要把转述写成源头确认过。
- 用 read_page 读源头原文，核对数字和条件，不要只看搜索摘要。

## 3. 解释说法为什么对不上

- 说法对不上，多半是口径不同：算的范围不同、时间不同、单位或币种不同、统计对象不同。逐条说明每种说法的口径和出处。
- 判断哪种说法有一手依据、哪种是误读或以讹传讹，并说明理由。口径不同不等于说错了。
- 证据不足以下结论时，直接说证据不足，以及还缺什么。
