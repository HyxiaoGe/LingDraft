# ask_user 自然触发探针（2026-10-28）

脚本 `backend/scripts/probe_ask.py`，结果 `run1.json`。跳过 intake，直接让调研 agent（DeepSeek V4 Pro 思考 high，当前提示词）面对一个选型任务；提示里不写“请提问”，不点名工具。

任务：给内部员工上知识库问答，在「调 DeepSeek 官方 API」和「私有化部署开源 DeepSeek」之间选一个，要明确推荐。关键的用户内部约束（文档能否出网）故意不给。

| 版本 | 次数 | 途中提问 | 结果 |
|---|---|---|---|
| 缺约束，若问则答“可以出网” | 2 | 0 / 2 | 一次“明确推荐私有化”（按“内部文档天然可能敏感”猜的，补充条件里才说不敏感可选 API）；一次条件式结论 |
| 缺约束，若问则答“不能出网” | 2 | 1 / 2 | 问了的那次：问题、选项、“不问会怎样”都合格，答“不能出网”后明确推荐私有化并引用 API 协议条款；没问的那次给“默认 API，敏感则私有化”的条件式结论 |
| 缺约束，若问则跳过 | 2 | 0 / 2 | 都是条件式结论（默认 API，列出反转条件），假设里写明了默认前提 |
| 补上约束（不能出网、有 A100 和运维） | 2 | 0 / 2 | 都不问，直接推荐私有化，64 / 80 秒 |

## 判断

- 管线：真实模型的一次提问走完了中断 → 回答 → 工具结果 → 继续 → 答案用到回答的全程，在进程内（内存检查点）通过。跨进程恢复和接口 / 前端的提问卡仍只有假模型覆盖。
- 该问时问：6 次缺约束只问了 1 次。模型更倾向于“给条件式结论”而不是问，哪怕用户要的是“明确推荐”。按 Codex 的三条标准，第三条“不能合理绕过”模型自己判断为可以绕过（分情况说明）。
- 边界：5 次没问里，4 次是诚实的条件式结论并写明假设；1 次（missing_A#0）把“内部文档天然可能敏感”这个猜测写成了“明确推荐私有化”，只在补充条件里留了后路，这是 Codex 说的“猜测包装成确定答案”，整理步骤把这个前提记进了假设，但正文结论没有体现。
- 信息齐全时不问：2 / 2。
- 跳过路径没测到（跳过版本两次都没问）。

## 没定的

要不要让模型在用户明确要“推荐一个”、关键约束又缺时更倾向于问。现在的提示词“关键条件不知道又没法问时给条件式结论”可能被读成“能给条件式结论就不用问”。这是产品取舍：问得少省一张卡，但“明确推荐”就只能是条件式的。

## 第二轮（提示词按 Codex 的完成标准改后，`run2.json`）

改动：系统提示和工具描述写明“用户要的是明确选择、一项没确认的用户约束足以翻转选择时，先问；分情况说明不算完成；只有用户跳过了才按标注假设给建议”，问法要问用户知道的具体事实、一个问题一件事、选项互斥、可以带“尚不清楚”。

| 版本 | 次数 | 途中提问 | 结果 |
|---|---|---|---|
| 缺约束，答“可以出网” | 3 | 3 / 3 | 三次都明确推荐官方 API，理由都是“私有化的唯一核心优势（数据不出内网）你们不需要” |
| 缺约束，答“不能出网” | 3 | 3 / 3 | 三次都明确推荐私有化，官方 API 直接排除 |
| 补上约束 | 3 | 0 / 3 | 直接推荐私有化，97～110 秒 |

六次提问的问法都是“公司是否允许把内部文档片段发送给外部 API”，选项是允许 / 不允许 / 尚不清楚（一次多了“部分可以”），“不问会怎样”都写明“不确认就只能给条件式结论，完不成你要的明确选择”。和 Codex 示例的问法一致，没有再把“内容敏感”和“公司禁止出网”捆在一起。

判断：该问时问 6 / 6，信息齐全时不问 3 / 3，用户不同回答确实翻转了推荐。第一轮的 1 / 6 是提示词把“条件式结论”当成了可接受的绕过方式；改成“用户要明确选择时分情况不算完成”后行为稳定。耗时 77～114 秒，和不问时相当。

## 第三轮：用户回答进整理、两条真实链路、换题（2026-10-28，Codex 的三项）

**先修**：途中提问的回答以前只在候选答案里，整理步骤看不到，把“没有合规限制”当成了模型假设。现在 research 节点从消息里收集一问一答存成 `asks`，整理步骤收到“用户确认的前提”（不需要来源佐证、不进 assumptions），报告单独一节“用户确认的前提”，items.json 导出 `user_fact`。跳过按钮按跳过处理：记一条假设，不算确认的前提。（第一版还用中文前缀判断“尚不清楚…”这类回答，第 4 轮撤掉了，见下。）

**链路 1：回答 + 跨进程恢复 + 前端**（线程 94dc9d47，`chain_answer_94dc9d47.json`）
Chrome 里提交知识库选型题 → intake 没问（需求清楚）→ 35 秒后 `research.ask` 卡出现 → 杀掉 uvicorn 重启新进程 → 接口 state 仍返回同一张提问卡 → Chrome 里点“不允许”→ 新进程恢复、继续调研 → 明确推荐私有化、官方 API 出局 → 报告“用户确认的前提”一节是这条回答，assumptions 里没有它 → asks_used 1、没有重复提问 → 校验全过、已导出。页面刷新后恢复线程是产品没有的功能（两个场景都没有），没验。

**链路 2：跳过**（线程 26197fd4，`chain_skip_26197fd4.json`，走 HTTP 接口）
问了一次 → 跳过 → 没有再追问 → 结论写成“由于「数据能否出内网」尚未确认……在默认假设 X 下推荐 API；若有不出网要求则私有化”，没有声称用户允许或禁止 → assumptions 第一条是“用户跳过了，按模型假设处理”。Chrome 这时断线了，“跳过”按钮没在页面上点，只验了它调用的接口。

**“尚不清楚”选项**（线程 cf39530c，`chain_unclear_cf39530c.json`）
选它之后结论同样是“在允许外发这一假设下推荐 API，若确认不出网则翻转”，语义对。但第一版代码把这个选项当成了用户回答，列进了“用户确认的前提”，已改成按跳过处理（见上）。

**换题**（`run3_django.json`，Django 升级到最新 LTS 的路径，取决于当前版本）
| 版本 | 次数 | 途中提问 | 校验 | 结果 |
|---|---|---|---|---|
| 缺当前版本，答 2.2 | 2 | 2 / 2 | 1 / 2 过 | 问“当前跑的是哪个版本”，选项按版本段分；答后给 2.2 → 3.2 → 4.2 → 5.2 分步路径 |
| 补上当前版本 | 2 | 0 / 2 | 1 / 2 过 | 直接给同一条分步路径 |

这轮验的是提问行为，提问行为 4/4 符合预期。但四次里有两次 `sources_complete` 没过（报告引用了来源表里没有的编号），这是来源完整性的问题，跟提问无关，单独记着，不算整份报告验收全过。

提示词里的例子是“公司是否允许把文档片段发给外部 API”，换到 Django 题模型问的是版本，说明不是在复述例子。

**结论**：ask_user 在这版里可用：缺用户约束会问、问法问具体事实、答案改变推荐、跳过不追问且结论标注假设、回答作为前提进报告、跨进程恢复正常。没验的：前端“跳过”按钮本身（Chrome 断线）、页面刷新恢复（无此功能）。

## 第 4 轮：撤掉中文前缀判断（2026-10-28）

第 3 轮把“尚不清楚…”选项按跳过处理，用的是中文前缀表（尚不清楚 / 不确定 / 不知道…）。Codex 用两句话复现了它的问题，我核实都成立：

- `我不太清楚，先按假设给建议` → 前缀表没有“我不太”，被当成确认的回答。
- `不确定预算，但公司明确禁止合同内容出网` → 整条被当成跳过，后半句明确的出网限制也丢了。

关键词表扩多少都兜不住自由文本。改成：**只有卡片上的“跳过”按钮算跳过**（载荷里有明确的 `skip` 标记）；自由文本原样记录，报告里那一节改叫“用户的回答”，整理步骤的提示词说明“明确给出的条件是已确认的前提，说不清楚的条件按假设处理并写进 assumptions”，由模型区分。提示词和工具说明里不再让模型给“尚不清楚”选项，页面的跳过按钮改成“说不清楚，按假设处理”。

**自由文本**（线程 ddb1e9e2，`chain_freetext.json`，走 HTTP 接口）
途中提问“公司是否允许把文档发给外部 API”，答“我不太清楚能不能出网，先按假设给建议” → 报告“用户的回答”一节原样记了这句 → assumptions 里有“用户表示「不太清楚能不能出网」，候选答案按保守假设处理” → 结论是条件式的：按保守假设推荐私有化，若确认可外发则改选 API → 校验全过。这次模型的默认假设取了保守方向（第 2、3 轮是“允许外发”），两种都标明了假设，可接受。

**前端跳过按钮**（线程 31f590a7，`chain_skip_ui.json`，Chrome 里点的）
这次提问卡只有三个实际选项，没有“尚不清楚”选项 → 点“说不清楚，按假设处理”按钮 → 没有追问 → 报告按三种假设给条件式结论，assumptions 第一条是“用户跳过了，按模型假设处理” → 校验全过、已导出。第 2 轮没在页面上点过的跳过按钮，这次补上了。

探针阶段到此结束：模型会不会问、问什么、答案怎么用，三轮加一轮修正都验过了。后面不再重复整套模型实验。
